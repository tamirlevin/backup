Busy Beaver · five states

Ten rules. 47,176,870 steps. One remainder decides when it stops.

This is the Busy Beaver champion for five states: of all Turing machines with five states and two symbols, the one that runs longest before it halts. It looks like noise. It is a counter. The picture below is the real machine, running in your browser.

The machine

Five states, ten rules, and a proof that nothing with five states runs longer

It starts on a blank tape in state A. Heiner Marxen and Jürgen Buntrock found it around 1990. In 2024 the bbchallenge collaboration proved, with a proof checked in Coq, that no five-state machine runs longer.

statereads 0reads 1
A1RB1LC
B1RC1RB
C1RD0LE
D1LA1LD
E1RH0LA

Each rule reads write, move, next state. 1RB means write 1, move right, go to state B. In the usual text notation the halting rule (state E reading 0) is left blank. I write it 1RH: write 1, move right, halt. The halting step counts as a step.

1RB1LC_1RC1RB_1RD0LE_1LA1LD_---0LA
One pass in JavaScript, on your device.

Not run yet. My C simulation gave 47,176,870 steps, 4,098 ones on the tape, 12,289 cells visited.

The rule

Every round starts from a block of ones, and n mod 3 decides the rest

The picture at the top shows one round. At 15 moments in the run, the tape is exactly one solid block of n ones, with the head just to its right in state D. The first time, n is 3. What the machine does next depends only on the remainder of n divided by 3.

0(5n² + 33n + 45) / 9(5n + 12) / 3 ones
1(5n² + 41n + 71) / 9(5n + 16) / 3 ones

I found these by watching the machine. I fitted the constants on the champion's own 14 rounds, then ran the actual machine from every block size from 1 to 250, and all 250 matched. 243 of those block sizes never occur in the real run. The picture at the top does the same test live for any n up to 150.

In the picture, amber diagonals are the head in state B carrying it right through the block, and violet diagonals are state D carrying it back. The white stripes are runs of zeros.

The whole run

Fifteen rounds, each about 5/3 the size of the last

Following the rule from n = 3 gives 3, 9, 19, 37, 67, 117 and so on, 15 blocks in all.

The streak

It survived 14 rounds. On average a start survives 2.

The rule is deterministic, so luck is only a description. Each round lands on remainder 2 about one time in three, and that stops the run. Start the same rule from a random block size and it survives k rounds with probability about (2/3)^k. Starting from 3, this machine dodged the exit 14 times in a row.

Six states

Add one state and the same idea becomes an open problem

Antihydra is a six-state machine found in 2024. Its tape holds a number and a counter, written as lengths of blocks of ones. The number starts at 8 and each round becomes a + ⌊a/2⌋: 8, 12, 18, 27, 40, 60, and on. The counter goes up 2 when the number is even and down 1 when it is odd. As described by the people who found it, the machine halts if the counter would ever go below zero.

I ran the real machine to 1010 steps and checked its tape against this description at all 24 checkpoints. The charts below run the arithmetic much further.

The counter drifts upward by about half a unit per round, so a halt looks astronomically unlikely. Nobody has proved it never happens. That question sits inside a six-state Turing machine, and answering it would settle a Collatz-like problem.

The longest-running six-state machine known is reported to take more than 2↑↑↑5 steps, a number no computer will ever count to.

Mistakes

I wrote down what I believed first. I was wrong twice.

Before writing any code I committed 21 statements about this topic to git, each with a confidence, plus 9 number ranges for quantities I had never seen. Then I checked. Of the 20 statements I could check, 18 came out as I said.

  • Antihydra's rule table (I said 20%)

    8 of the 12 entries I wrote down were right and 4 were wrong. My version looks as plausible as the real one and halts after 10 steps. Only running it showed the difference.

  • The 3-state machine with the most ones (I said 75%)

    I said it stops after 11 steps. Five different machines tie for the most ones, and they take 11, 12, 13, 13 and 14 steps.

All 9 number ranges contained the truth. About 7 would be expected, so my ranges were probably too wide, though 9 is too few to be sure. My point guesses for the size of the search were 2.2 to 2.5 times too high, three times in a row. Twenty items that I chose myself make an anecdote, not a calibration curve.
